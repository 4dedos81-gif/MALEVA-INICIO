# MALEVA-INICIO
I.V.E. Ingeniería variable emergente MALEVA
🔹 Concepto narrativo para un público normal
M1: capa ligera que toca el mundo; detecta golpes, presiones y vibraciones. Puede funcionar sola como protección básica.
M2: puente y guía; toma lo que M1 detecta y lo organiza para que llegue al interior. Funciona sola como canalizador pasivo de energía y deformaciones.
M3: el núcleo inteligente; interpreta lo que llega y puede actuar, retroalimentar o modificar el sistema. Funciona sola como un sensor-actuador autónomo, pero su máxima eficacia es cuando recibe señales de M1 y M2.
